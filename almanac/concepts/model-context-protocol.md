# Model Context Protocol (MCP)

Model Context Protocol (MCP) is an open standard that enables AI applications to connect to external tools, data sources, and services through a standardized interface. This repository exists as a resource hub for a talk on MCP at MeasureCamp Madrid 2025, providing links to documentation, examples, client implementations, and tools that support MCP integration.

## Why This Repository Exists

The repository was created to support a presentation on Model Context Protocol at MeasureCamp Madrid 2025. It serves as a curated collection of resources for talk attendees, linking to official documentation, implementation examples, client ecosystems, and practical guides for integrating MCP into development workflows.
